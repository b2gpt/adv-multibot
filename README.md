# multi-converter-bot

## Useful commands and behavior

- `/start` or `/help` — open the point-wise Functions and Commands menu. The **Other Bots** page shows the same bot links to every user. The owner can add a link there with `Bot Name | https://t.me/botusername` (or `Bot Name | @botusername`) and remove links from the same page. Bot links are saved in `other_bots.json`, or in the shared MongoDB `_bot_metadata` collection when `MONGODB_URI` is configured. `OTHER_BOTS` remains supported to seed the list on first startup.
- `/settings` — choose whether uploads are sent as Video or File and toggle Rename File.
- `/addthumb` and `/delthumb` — set or remove your custom video thumbnail.
- Send a photo to open image tools: set it as a thumbnail, convert to JPG/PNG/SVG/PDF, compress to under 20/50/100 KB, or resize to a preset/custom maximum resolution. SVG output embeds the raster image rather than vectorizing it.
- Send a PDF to choose **Keep Original**, **Add Watermark**, or **Remove Text Watermark**. For removal, provide the exact searchable watermark text. This redacts matching text regions and may also affect document content underneath; scanned/flattened image watermarks are not automatically removable.
- `/bulk`, `/forward`, and `/done` — collect and process multiple videos; optionally send bulk results to another channel.
- `/merge` — collect videos for merging; use `/done` when finished.
- `/channelcopy` and `/copycancel` — copy media from an accessible channel range and cancel a pending setup. For a private source, add the bot account itself to that channel; your personal-account membership does not grant the bot access.
- `/extracturl <URL>` and `/makearchive <URL>` — extract an archive from a direct link or create one from direct file and supported media links.
- `/filecompress` — collect Telegram photos, videos, audio, PDFs, and documents; send `/done`, then choose ZIP, 7Z, RAR, or TAR.GZ.
- `/fileextract` — extract a ZIP, 7Z, RAR, or TAR uploaded in Telegram, or provide a direct archive URL.
- Send a supported direct file URL (image, video, audio, document, or archive) to download it. Direct archive URLs are extracted; other files are sent in their matching Telegram media type where supported. Google Drive and other recognized hosts use yt-dlp; host access and file support depend on the link and installed yt-dlp version.
- Send multiple URLs (one per line or in one message) to download the supported files and choose ZIP, 7Z, RAR, or TAR.GZ. This works with direct file links and yt-dlp-supported links, including public Google Drive, Instagram, and YouTube URLs.
- `/info` — view your information; the owner can use `/info @username` to inspect another user.
- `/grant`, `/deny`, and `/users` — owner-only access management.
- `/cancel` — cancel your pending interactions and active jobs; `/stop` — owner-only global stop that cancels active jobs for all users and resets pending sessions. Bulk range scanning also shows a cancel button. Already delivered Telegram files/messages cannot be recalled.
- Access permissions for `/grant`, `/deny`, and `/users` use MongoDB when `MONGODB_URI` is configured. Set `MONGODB_URI` to your Atlas connection string and optionally set `MONGODB_DATABASE` (default `multi_converter_bot`). The Atlas database user needs read/write access to that database, and the cluster network access list must allow the bot host. Store the URI as a deployment secret; do not commit it. On the first MongoDB startup, existing `users.json` grants are imported once if the MongoDB `allowed_users` collection is empty. Without `MONGODB_URI`, the bot continues using local `users.json`.
- `/addthumb` — reply to a photo or send a photo after the command to set your own video thumbnail. The setting is per Telegram account.
- `/delthumb` — remove your custom thumbnail and return to the automatic video cover.
- `/extracturl` — download and extract one direct-link ZIP, 7Z, RAR, or TAR archive. `/extracturl <URL>` can be used in one command.
- `/makearchive` — download one or more direct file or supported media URLs (one per line or in one message) and create a ZIP, 7Z, RAR, or TAR archive. `/makearchive <URL>` starts with one link.
- Send a public YouTube or Instagram video URL in a private chat to download and receive the video as a reply. Playlists are restricted to one video; private/login-gated videos are not supported. `yt-dlp[default]` is used, and FFmpeg must be installed for formats that need merging. YouTube downloads may also require a supported JavaScript runtime such as Deno as platform protections change. The downloaded original is also uploaded to the permanent channel.
- YouTube links show a quality chooser (Best, up to 2160p/1440p/1080p/720p/480p/360p) and MP3 option. A selected resolution is a maximum; the exact quality depends on the source formats available. If YouTube requires sign-in or blocks the server, configure `YTDLP_COOKIES` with a securely stored Netscape-format cookie export from an account authorized to view the video. Never commit or share the cookie file; YouTube access can still change or be unavailable. MP3 conversion requires FFmpeg on the server. Instagram post, reel, and story links are accepted; stories/private content generally also require authorized cookies.
- Google Drive, TeraBox, MediaFire, MEGA, and `filestore.to` URLs are recognized as media links and sent through the available site downloader. MEGA requires `megadl` from megatools on the server (`MEGADL_EXECUTABLE` can point to its executable). Other file hosts depend on support in the installed yt-dlp version and may reject login-protected, expired, or unsupported links.
- Social video downloads are limited by `MAX_SOCIAL_BYTES` (default 2 GiB). `yt-dlp` support changes as platforms change; update dependencies if a site stops working.
- Archive URL downloads are limited by `MAX_DIRECT_BYTES` (default 2 GiB). Extraction is capped by `MAX_EXTRACTED_BYTES` (default 5 GiB) and `MAX_ARCHIVE_FILES` (default 500 entries). Links to private/local network hosts and unsafe archive paths are rejected. ZIP/TAR are built in; 7Z uses `py7zr`; RAR extraction uses `rarfile` and needs an UnRAR/7-Zip backend, while RAR creation needs WinRAR/RAR CLI. Set `RAR_EXECUTABLE` if the tool is not on `PATH`.
- `/bulk` — send videos or provide two `t.me` message links for a group/channel range, then run `/done`. Only video messages in a linked range are selected; other message types are skipped. The regular processing menu is available after `/done`, and each processed video has its own live progress message. For stream actions, the first video's selected stream indexes are reused across the batch.
- `/channelcopy` — copy media between two `t.me` message links to a destination channel. The bot must already be able to read the source (invite it to private channels) and be an admin allowed to post in the destination. Jobs run one at a time with at least a 1.5-second gap between copied media; the range limit is `MAX_RANGE` (default 2000). Deleted, text-only, and protected messages are skipped, and each Telegram copy request has a 45-second timeout. Telegram-requested FloodWait delays are honored. This uses the bot identity, does not auto-join channels, does not use a personal-account session, and cannot bypass protected-content restrictions or guarantee against Telegram limits. In-memory queued jobs do not survive a bot-process restart.
- Original media and each processed result are re-uploaded (not Telegram-forwarded) to the permanent channel `-1004289007980`, so they have no forwarded-from label. The bot must be an admin with post permission there. Set `PERMANENT_CHANNEL_ID` to change the destination.
- During `/bulk`, use `/forward <channel_id>` or `/forward @channelusername` to add a second destination for that batch. The permanent channel still receives copies; the extra channel is per-run only. The bot must be an admin with post permission in both channels.
- `Media Information` — reports embedded creation-date metadata when available and the Telegram upload date. Telegram does not expose a user's account creation date.
- M3U8 archives include the selected quality, source resolution for the original-quality archive, and archive size in the filename/caption.

Processed video outputs use a light `codextrms` watermark that changes position during playback. Set `WATERMARK` to an empty value to disable it.
